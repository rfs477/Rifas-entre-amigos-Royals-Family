Guía rápida

Cómo participar

  1. Elige una rifa y toca los números que te interesan.
  2. Escribe tu nombre y teléfono de contacto.
  3. Envía la solicitud por WhatsApp para que administración revise la disponibilidad.
  4. Realiza la transferencia únicamente después de recibir instrucciones de pago.
  5. Envía el comprobante por WhatsApp. El número queda confirmado cuando se valida el pago y se actualiza el registro.
  6. Consulta la fecha, mecánica y reglas particulares publicadas para cada rifa.
Participar no garantiza premio. Las rifas con venta de boletos pueden requerir autorización conforme a la legislación mexicana. Verifica los permisos aplicables antes de ofrecer rifas al público.

Transparencia

Administración

Este panel guarda los cambios solo en este navegador y dispositivo. No tiene contraseña segura ni sincronización pública. No lo uses como registro definitivo de ventas.

Para una operación real con varios clientes y administración desde cualquier celular, hace falta una base de datos compartida y control de acceso. No guardes datos bancarios ni comprobantes sensibles en esta versión.
